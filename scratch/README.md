kept for transparency only. They assume the `src/` layout and a local `.env`, so they may
not run as-is from here.

| File | What it was for |
|---|---|
| `hello_claude.py` | First API call – checking key, model and cost per call |
| `explore*.py` | Inspecting API-Football / OddsPapi responses before writing the fetch scripts |
| `import_excel.py` | One-off import of the archived Excel sheet (rounds 1–10, 2026/27) |
| `predict_round.py` | Old Excel-era prediction script, replaced by `src/predict_upcoming.py` |
